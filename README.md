# R
If you don't have R in your own device, you can copy the code and paste it to run it here: https://rdrr.io/snippets/
* [Riemann sum with partitions of the same length](https://github.com/juigmend/R-miscellaneous/blob/main/Riemann_sum.R) computes the sum and also makes a visualisation with the function and rectangles. It may be edited to specify different functions and parameters such as the number of partitions, tag point and visualisation interval.

* MC Lauri is a Finnish stand-up comedian, and MC Laurin means "of MC Lauri" in Finnish. Apart from the phonetic similarity, that has nothing to do with the Maclaurin series for approximating functions. What does have to do with it is [this little program](https://github.com/juigmend/R-miscellaneous/blob/main/Maclaurin_approx_to_sine) that shows an approximation to the sine function near zero, using the Maclaurin series. The program shows what happens when you change the number of iterations and the domain interval. Also it shows the RMS error.
