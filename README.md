# [R](https://cran.r-project.org/) miscellaneous
If you don't have R in your own device, you can copy the code and paste it to run it here: https://rdrr.io/snippets/
* [Riemann sum with partitions of the same length](https://github.com/juigmend/R-miscellaneous/blob/main/Riemann_sum.R) computes numerical integration and makes a visualisation with the function and blocks. It may be edited to specify different [functions](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L9-L12) and parameters such as the [bounds](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L14-L15), [number of partitions](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L6), [tag points](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L7), and [visualisation interval](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L28-L29). The code is written redundantly so that the [first loop](https://github.com/juigmend/R-miscellaneous/blob/798836ea80def82f494e7c869890e88923847b0b/Riemann_sum.R#L17-L22) corresponds as close as possible to the [formula](https://youtu.be/GCHr1oXP6a0?t=596).

* MC Lauri is a Finnish stand-up comedian, and MC Laurin means "of MC Lauri" in Finnish. Apart from the phonetic similarity, that has nothing to do with the Maclaurin series for approximating functions. What does have to do with it is [this little program](https://github.com/juigmend/R-miscellaneous/blob/main/Maclaurin_approx_to_sine) that shows an approximation to the sine function near zero, using the Maclaurin series. The program shows what happens when you change the [number of iterations](https://github.com/juigmend/R-miscellaneous/blob/ada5a6d6ce4bdd1b25d1886e4845934b498ccea0/Maclaurin_approx_to_sine.R#L6) and the [domain interval](https://github.com/juigmend/R-miscellaneous/blob/ada5a6d6ce4bdd1b25d1886e4845934b498ccea0/Maclaurin_approx_to_sine.R#L7-L8). Also it shows the RMS error.
